# 视频分镜脚本规范

分镜脚本把「转写文本 + 关键帧 + 时间轴」转成可拍摄/可剪辑的执行表。

## 一、两种模式

| 模式 | 用途 | 时间轴来源 |
| --- | --- | --- |
| **复刻型** | 还原对标视频的镜头节奏，供剪辑参考 | 沿用原 SRT 时间码 |
| **改编型** | 按新口播稿重新排镜 | 按语速预算重新排布 |

复刻型必须对齐原时间轴；改编型不继承原时间码，只继承节奏比例。

## 二、时间锚点规则（硬性）

1. 每个分镜行必须带 `起止时间`，精确到秒：`00:02:31 - 00:03:05`。
2. 时间码取自 `load_post.py --captions` 的真实 SRT 时间戳，**不得编造**。
   长视频用 `--range 00:00:00-00:03:00` 分段取出，逐段填表。
3. 分镜切分点优先落在：话题切换、举例开始、金句出现、画面明显变化处。
4. 关键帧用 `--locate HH:MM:SS` 反查，标注为**估算**参考：
   `参考帧：抽帧_067.jpg（约 00:05:32，误差 ±5s）`。

## 三、分镜表字段

| 字段 | 说明 |
| --- | --- |
| 序号 | 从 1 开始 |
| 时间码 | `起 - 止`，秒级 |
| 时长 | 该镜停留秒数 |
| 画面内容 | 客观描述画面里有什么（从关键帧读取，不臆测） |
| 景别/运镜 | 特写 / 中景 / 全景 / 推拉摇移；双人访谈常为「过肩+正反打」 |
| 口播 | 该时间段实际说的话（复刻型填原文，改编型填新稿） |
| 字幕/花字 | 需要上屏的关键词，只放 4–8 字 |
| 音效/BGM | 情绪提示 |
| 参考帧 | `抽帧_XXX.jpg` |

## 四、读取画面的正确做法

1. 先 `--frame-sample 6` 拿到全片均匀代表帧，建立整体印象。
2. 对每个分镜的时间点用 `--locate` 取对应帧。
3. 用 Read 逐张看图，**一次不超过 6 张**，避免上下文爆掉。
4. 描述只写看得到的东西：人数、场景、字幕板、图表、特写对象。
   看不到细节时写「画面信息不足，需回看原视频」，**不要编造画面**。

## 五、语速与字数预算（改编型）

| 项目 | 参考值 |
| --- | --- |
| 中文口播语速 | 240–300 字/分钟（信息类偏慢，情绪类偏快） |
| 60 秒短视频 | 250–320 字 |
| 3 分钟中视频 | 750–950 字 |
| 单镜停留 | 访谈 8–20 秒；强节奏剪辑 2–5 秒 |

`load_post.py` 的 `charsPerMinute` 可作参考，但**ASR 会把开场重复收录一遍**，
导致该值虚高（实测可到 470）。换算字数时应先用 `outline` 剔除重复段落再估算。

## 六、ASR 文本处理

- `[音效]` `[笑]` `[音乐]` 等非语言标记一律删除（`load_post.py` 默认已处理）。
- 口语 filler（"嗯""啊""那个"）在改写为字幕时应删除，但**复刻型口播栏保留原样**以还原真实节奏。
- 断句错误：ASR 常在一句话中间换行，合并段落后再使用。
- 转写开头若与后文重复（常见于访谈开场），只保留一次。

## 七、交付检查

- [ ] 每个分镜都有真实时间码
- [ ] 画面描述均来自实际查看的帧，无编造
- [ ] 参考帧标注了「约」和误差范围
- [ ] 总时长与原片一致（复刻型）或与目标时长一致（改编型）
- [ ] 无整段搬运原口播（改编型）
